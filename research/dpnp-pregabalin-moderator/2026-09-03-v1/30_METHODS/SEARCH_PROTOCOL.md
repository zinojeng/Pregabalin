# Search and Evidence Protocol

## Coverage

- Databases/sources: PubMed/NCBI, Crossref/OpenAlex or equivalent metadata sources, guideline organizations, regulators, trial registries, and validated configured research MCPs.
- Recency window: prioritize 2020-09-03 through 2026-09-03; retain older landmark trials/guidelines when still current or decision-relevant.
- Languages: English and Traditional Chinese; do not exclude otherwise relevant evidence solely by language without recording the decision.

## Core concepts

1. diabetes / diabetic neuropathy / distal symmetric polyneuropathy
2. painful diabetic peripheral neuropathy / neuropathic pain
3. diagnosis / screening / small fiber / nerve conduction / differential / red flags
4. guideline / consensus / recommendation
5. Pregabalin and comparator classes
6. efficacy / responder / sleep / function / adverse event / discontinuation / renal / misuse / withdrawal

## Inclusion priorities

- Current authoritative guidelines and regulatory documents.
- Systematic reviews/meta-analyses with transparent methods.
- Pivotal or practice-changing RCTs, recent head-to-head and combination trials.
- High-quality observational safety/implementation evidence where RCTs are unsuitable.

## Extraction rule

Capture exact population, intervention/dose, comparator, duration, outcome definition, numeric result, uncertainty, harms, funding/COI, and source locator. Never infer a missing number.
